# Archived batch scripts (v5–v22)

Superseded by `scripts/apply_batch.py`.

These were 20+ near-identical copies, each created by copy-pasting the previous round's
script. That is precisely how the same bugs shipped repeatedly and why fixes had to be
applied by hand in several places at once. Kept only as a record of what was sent in each
round; do not run them — they contain the pre-fix filter logic.
